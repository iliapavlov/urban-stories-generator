# 📸 Urban Story Ideas Generator for Fundraising

CLI-інструмент на базі Google Gemini Vision API для автоматичного аналізу вуличних фотографій та генерації концептів сторіз для мікрозборів на допомогу військовим.

Проєкт виріс із відчуття глухого кута у звичних підходах до зборів. На довгій дистанції ресурси людей вичерпуються — і матеріальні, і емоційні. До втоми додається гіркий контекст корупційних скандалів, що б’є по відчуттю справедливості, а в публічному просторі дедалі частіше відчувається напруга від взаємних очікувань, докорів та втоми сумління.

Цей інструмент — спроба змінити тональність розмови: не вимагати й не повчати, а шукати опору в повсякденній міській реальності та прямій солідарності «рівний рівному». Це спосіб підтримувати своїх без пафосу, зберігаючи гідність кожного — і того, хто просить, і того, хто відгукується.

## ✨ Можливості

- **Інтерактивний режим співавторства (`--interactive`):** Покроковий діалог із моделлю для глибокого аналізу та швидкого внесення правок.
- **Двоетапний Deep Dive аналіз:** Попереднє виявлення неочевидних візуальних артефактів, світлових акцентів та міського мікроконтексту перед написанням текстів.
- **Гарантована структура виводу (Structured Outputs):** Генерація через Pydantic-схеми забезпечує стабільний формат відповідей (фокус, спостереження, рефлексія, CTA) без збоїв форматування.
- **Стійкість до збоїв API (Auto-retry & Recovery):** Автоматичні повтори запитів за алгоритмом Exponential Backoff при помилках `503 UNAVAILABLE` або `429 RATE LIMIT` зі збереженням стану сесії.
- **Гнучке збереження даних:** Створення зручних для читання Markdown-файлів (`.md`) та опційне збереження валідованого JSON (`.json`) для подальшої автоматизації або інтеграції.
- **Фоновий моніторинг папки (`--watch`):** Автоматична обробка нових фотографій у реальному часі.

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone https://github.com/iliapavlov/urban-stories-generator.git
cd urban-stories-generator
```

### 2. Налаштування середовища (venv)

Створіть віртуальне середовище та активуйте його:

```bash
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
```

Встановіть залежності:

```bash
pip install -r requirements.txt
```

> **Вміст `requirements.txt`:**
>
> ```text
> google-genai>=0.1.1
> pillow>=10.0.0
> watchdog>=4.0.0
> python-dotenv>=1.0.0
> pydantic>=2.0.0
> ```

### 3. Конфігурація

Створіть файл `.env` у кореневій папці проекту:

```bash
GEMINI_API_KEY=ваш_api_key_тут

# Опціональні налаштування (за замовчуванням):
GEMINI_MODEL=gemini-3.6-flash
SAVE_JSON=false
```

- GEMINI_API_KEY — ключ доступу (отримати ключ API можна на [aistudio.google.com](https://aistudio.google.com/)).
- GEMINI_MODEL — назва моделі Gemini (за замовчуванням gemini-3.6-flash).
- SAVE_JSON — автоматично зберігати сирий JSON поруч із .md файлами (true / false).

### 4. Структура промптів

Усі системні та робочі інструкції винесені в окремі текстові файли в директорії prompts/:

```text
prompts/
├── system_role.txt       # Глобальна ідентичність, тон та філософія спостереження
├── deep_dive.txt         # Крок 1: детальний фактологічний аналіз кадру
└── story_generation.txt  # Крок 2: правила побудови структури сторіз
```

#### ⚙️ Директорії за замовчуванням

  - `input_photos/` — папка для вихідних фотографій (`.jpg`, `.jpeg`, `.png`, `.webp`).
  - `output_ideas/` — папка для згенерованих чернеток у форматі `.md`.

## 💻 Використання

### 1. Інтерактивний режим (Рекомендований)

Запускає діалог для аналізу конкретного кадру, вибору смислового акценту та ітеративного доопрацювання:

```bash
python main.py --interactive input_photos/photo.jpg
# або скорочено:
python main.py -i input_photos/photo.jpg
```

Як це працює:

    1. Модель проводить Deep Dive аналіз і виводить у термінал неочевидні деталі кадру.
    2. Ви вказуєте конкретний фокус (або тиснете Enter для автоматичного вибору).
    3. Модель генерує 3 структуровані варіанти сторіз.
    4. Refinement Loop: ви можете писати зауваження в консоль (наприклад, "зроби 2 варіант більш іронічним"), і модель оновлюватиме варіанти зі збереженням контексту.
    5. Натискання Enter на порожньому рядку зберігає затверджений результат.

### 2. Фоновий моніторинг папки

Безперервно відстежує появу нових фотографій у теці та автоматично генерує чернетки:

```bash
python main.py --watch
```

### 3. Пакетна обробка [Deprecated]

Обробити всі наявні файли в папці без діалогу:

```bash
python main.py --batch
```

### Додаткові параметри CLI

- --save-json — примусово зберегти структурований JSON поруч із Markdown:

```bash
python main.py -i input_photos/photo.jpg --save-json
python main.py --watch --save-json
```

--input та --output — перевизначення стандартних папок:

```bash
python main.py --watch --input ./my_photos --output ./my_stories
```

## 📁 Результати

генеровані матеріали зберігаються в папці output_ideas/. При використанні інтерактивного режиму файл Markdown містить і первинний Deep Dive аналіз, і фінальні затверджені тексти:

```text
output_ideas/
├── IMG_20260912_133238_stories.md
└── IMG_20260912_133238_stories.json
```

### Структура збереженого Markdown:

    - 🔍 Первинний Deep Dive аналіз: перелік зафіксованих візуальних деталей та контексту кадру.
    - Ключовий візуальний фокус: головна смислова лінія генерації.
    - Варіанти 1–3:
        - Слайд 1 (Спостереження): прив'язка до конкретної візуальної деталі на фото.
        - Слайд 2 (Рефлексія/Вибір): зміна сприйняття, перехід від рутини чи роздратування до усвідомленої позиції дії.
        - Слайд 3 (Call-to-Action): органічна інтеграція лінка або стікера на банку.

### ⚠️ Важливо

- Модель генерує філософську основу для рефлексії та робочі чернетки — завжди переглядайте тексти та адаптуйте лінк/стікер під конкретний актуальний збір.
- Не передавайте моделі фотографії, що містять конфіденційні військові об'єкти, переміщення техніки, блокпости або розпізнавальні знаки з прив'язкою до чутливих локацій.
