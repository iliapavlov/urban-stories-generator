# 📸 Urban Story Ideas Generator for Fundraising

CLI-інструмент на базі Google Gemini Vision API для автоматичного аналізу вуличних фотографій та генерації концептів сторіз для мікрозборів на допомогу військовим.
Натхненний втомою від агресивного збору донатів через почуття провини та небажанням писати шаблонні пафосні тексти. Інструмент фокусується на зміні оптики повсякденного міського простору та цінності прямої взаємодії «людина для людини».

## ✨ Можливості

- **Vision-аналіз:** Автоматичне розпізнавання тексту, світлових акцентів та деталей міського побуту на фотографіях.
- **Два режими роботи:** Пакетна обробка архіву фотографій (`--batch`) або безперервний фоновий моніторинг папки (`--watch`).
- **Розумний кеш:** Пропуск уже оброблених фотографій для економії токенів та уникнення дублікатів.
- **Контроль лімітів:** Вбудована затримка між запитами (rate limit delay) для стабільної роботи з API.

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone https://github.com/iliapavlov/urban-stories-generator.git
cd urban-stories-generator
```

### 2. Налаштування середовища (venv)

Створіть віртуальне середовище та активуйте його:

```bash
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
```

Встановіть залежності:

```bash
pip install -r requirements.txt
```

> **Вміст `requirements.txt`:**
>
> ```text
> google-genai>=0.1.1
> pillow>=10.0.0
> watchdog>=4.0.0
> python-dotenv>=1.0.0
> ```

### 3. Конфігурація

Створіть файл `.env` у кореневій папці проекту:

```bash
GEMINI_API_KEY=ваш_api_key_тут
```

Отримати ключ API можна безкоштовно на [aistudio.google.com](https://aistudio.google.com/).

#### ⚙️ Директорії за замовчуванням

Скрипт автоматично створить необхідні каталоги під час першого запуску, але за потреби ви можете створити їх заздалегідь:

```bash
mkdir input_photos output_ideas
```

- `input_photos/` — папка для вихідних фотографій (`.jpg`, `.jpeg`, `.png`, `.webp`).
- `output_ideas/` — папка для згенерованих чернеток у форматі `.md`.

### 4. Використання

Запустіть скрипт із потрібним прапорцем:

- **Пакетна обробка наявних фото:**
  ```bash
  python main.py --batch
  ```

- **Фоновий моніторинг нових фото в реальному часі:**
  ```bash
  python main.py --watch
  ```

- **Використання власних шляхів (опціонально):**
  ```bash
  python main.py --batch --input /шлях/до/фото --output /шлях/до/чернеток
  ```

### 5. Результати

Згенеровані чернетки зберігаються в папці `output_ideas/` у форматі Markdown із трьома готовими варіантами сторіз (деталь → рефлексія/вибір → банка):

```text
output_ideas/
├── IMG_2026_09_12_01_stories.md
└── IMG_2026_09_12_02_stories.md
```

### ⚠️ Важливо

- Модель генерує філософську основу для рефлексії та робочі чернетки — завжди переглядайте тексти та адаптуйте лінк/стікер під конкретний актуальний збір.
- Не передавайте моделі фотографії, що містять конфіденційні військові об'єкти, переміщення техніки, блокпости або розпізнавальні знаки з прив'язкою до чутливих локацій.
